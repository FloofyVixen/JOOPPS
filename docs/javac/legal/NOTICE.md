# javac21.jar

`javac21.jar` holds the unmodified class files of three OpenJDK 21 modules,
`jdk.compiler`, `jdk.internal.opt` and `java.compiler`, taken from the
OpenJDK 21.0.12.1 build (Ubuntu package `openjdk-21`). The course's Run button uses it
to compile learners' code in the browser.

`ASSEMBLY_EXCEPTION` and `jopt-simple.md` are the module-specific notices
shipped with the JDK.

Source code: https://github.com/openjdk/jdk21u (upstream) and the Ubuntu
`openjdk-21` source package (`apt-get source openjdk-21`).
